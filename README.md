How to setup 101

1. Setup an invidious instance, follow this guide > https://docs.invidious.io/installation/
2. Configure the instance url with port if needed in the config.php file
3. Put the files on a PHP enabled web server, Recommended is XAMPP as that's what's been used while developing
4. Before use remove the file "removebeforeuse" in the cache folders, not the folders themselves

Enjoy!
